# سپهر ۳ 🔭

**رصدگاه فارسی نجوم برای اندروید**؛ از بررسی آسمان و پیدا کردن جرم‌های اعماق فضا تا برنامه‌ریزی جلسه، ثبت تجربه و محاسبه‌ی ابزار. نسخه‌ی ۳ یک فضای تازه‌ی «رصدگاه» به اپ اضافه می‌کند و در کنار قابلیت‌های نسخه‌ی ۲، ۲۰ ابزار و مسیر تازه‌ی رصدی دارد.

[![Build APK](../actions/workflows/build-apk.yml/badge.svg)](../actions/workflows/build-apk.yml)

## ۲۰ قابلیت تازه‌ی نسخه‌ی ۳

1. **فهرست اعماق آسمان** با ۱۸ هدف منتخب از کاتالوگ‌های مسیه و NGC؛ جست‌وجو و فیلتر بر پایه‌ی نوع جرم، نام و صورت فلکی.
2. **مختصات افقی زنده‌ی هر هدف**؛ ارتفاع و سمت محاسبه‌شده برای مکان انتخاب‌شده و زمان فعلی.
3. **اوج ارتفاع در ۱۲ ساعت آینده** همراه با ساعت محلیِ بهترین بازه‌ی تقریبی.
4. **پنجره‌ی پیشنهادی رصد** برای زمانی که جرم دست‌کم ۲۰ درجه بالاتر از افق هندسی است.
5. **راهنمای پرش ستاره‌ای** و نکته‌ی رصدی فارسی برای هر جرم فهرست.
6. **پیشنهاد هدف‌های امشب** با رتبه‌بندیِ ارتفاع، درخشندگی ظاهری و تناسب با تاریکی محل.
7. **پروفایل Bortle جداگانه برای هر مکان رصد** که روی دستگاه ذخیره می‌شود.
8. **برآورد قدر حدی چشم غیرمسلح** از روی کلاس Bortle انتخاب‌شده.
9. **شاخص آموزشی شفافیت جو** با استفاده از ابر، دید افقی و رطوبت پیش‌بینی‌شده.
10. **هشدار ریسک شبنم/یخ‌زدگی** از فاصله‌ی دمای هوا تا نقطه‌ی شبنم.
11. **فهرست برنامه‌ی رصد ماندگار** برای نگه‌داشتن هدف‌های انتخاب‌شده بین اجراهای اپ.
12. **مرتب‌سازی و حذف هدف‌های برنامه** برای ساخت ترتیب شخصی جلسه.
13. **زمان‌سنج جلسه‌ی میدانی** با شروع، مکث و بازنشانی.
14. **دفترچه‌ی رصد محلی** با زمان، هدف، مدت، امتیاز تجربه و یادداشت.
15. **خروجی متنی دفترچه** برای کپی در کلیپ‌بورد و نگهداری پشتیبان.
16. **چک‌لیست تجهیزات شخصی‌سازی‌شدنی** با امکان افزودن/حذف وسیله و ذخیره‌ی وضعیت هر مورد.
17. **محاسبه‌گر حد تفکیک داوز** از روی قطر دهانه‌ی تلسکوپ.
18. **محاسبه‌گر میدان دید واقعی چشمی** از میدان ظاهری و بزرگ‌نمایی.
19. **راهنمای نوردهی عکاسی نجومی** با قانون تقریبی ۵۰۰ و ضریب برش دوربین.
20. **قاب‌بندی حسگر دوربین و راهنمای هم‌راستاسازی قطبی** با توجه به نیم‌کره و عرض جغرافیایی.

قابلیت‌های نسخه‌ی ۲ نیز حفظ شده‌اند: امتیاز و پیش‌بینی هوا، فاز ماه و تقویم رویداد، نقشه‌ی ستاره‌ها، ردیاب ISS، بایگانی APOD، کوییز، مکان‌های ذخیره‌شده و ابزارهای عمومی رصد.

## دریافت APK نسخه‌ی ۳

پس از اجرای موفق GitHub Actions، از بخش **Artifacts → sepehr-apk** فایل ZIP را دریافت و `app-release.apk` را از آن خارج کن. انتشار تگ نسخه‌ای مانند `v3.0.0` نیز APK را به‌عنوان فایل مستقیم در GitHub Releases قرار می‌دهد.

## ساخت محلی

از پوشه‌ی ریشه‌ی مخزن:

```bash
cd sepehr_app
flutter create . --platforms=android --org com.sepehr --project-name sepehr
flutter pub get
flutter test
flutter build apk --release
```

Workflow در `.github/workflows/build-apk.yml` مجوز اینترنت و مکان را به Manifest اندروید اضافه می‌کند. برای ساخت دستی، این مجوزها باید بالای `<application>` در `android/app/src/main/AndroidManifest.xml` باشند:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
```

برای محدودیت کمتر NASA APOD، در GitHub Actions یک secret به نام `NASA_KEY` قرار بده؛ در غیر این صورت اپ از `DEMO_KEY` استفاده می‌کند.

## دقت و حریم داده

مکان، برنامه، Bortle، تجهیزات و دفترچه روی دستگاه ذخیره می‌شوند؛ دفترچه به سرور ارسال نمی‌شود. مختصات کاتالوگ و زمان پنجره‌های رصد تقریبی‌اند. شاخص شفافیت از پیش‌بینی عمومی ساخته می‌شود و **seeing واقعی را اندازه‌گیری نمی‌کند**. کلاس Bortle باید با ارزیابی خود رصدگر تنظیم شود؛ زمان‌های پیشنهادی جایگزین بررسی افق و شرایط واقعی نیستند. قانون ۵۰۰ و حد داوز نیز تقریب‌های آموزشی‌اند.
